# Process Raid Guild

실제 컴퓨터 프로세스와 시스템 사용량을 픽셀 아트 협동 보스전으로 보여주는 Windows 데스크톱 앱입니다.

## 특징

- Unity, AI 도구, IDE, 브라우저, 빌드 도구를 헌터로 자동 분류
- 고부하 작업을 보스/정예/졸개 몬스터로 시각화
- 활성 헌터는 전장으로 이동·순찰하고, 유휴 헌터는 캠프로 이동해 식사·수면·칼갈기·모닥불 준비
- 동시 활동 헌터끼리 전략 두루마리·정찰 정보·수리 도구·회복 식량을 주고받는 협업 연출
- CPU, 메모리, GPU, 프로세스 수를 2.5초마다 로컬에서 갱신
- 프로세스 명령 내용은 UI에 노출하지 않으며 외부 서버 전송 없음
- 저작권 에셋 없는 자체 Canvas 픽셀 아트
- 다층 시네마틱 전장 배경, 직업별 문장·장비, 기계형 보스 오라, 투사체·충돌 파티클을 포함한 강화 그래픽
- 6종 헌터 전신 벡터 스프라이트와 보스·정예·졸개 3등급 전용 기계 몬스터 스프라이트

> 이 앱의 전투력과 위협도는 시스템 사용량을 이해하기 쉽게 표현한 시각화이며, 생산성 또는 작업 성공 여부를 판정하지 않습니다.

## 개발 실행

```bash
npm install
npm test
npm start
```

## Windows 배포 파일 만들기

```bash
npm run dist
```

`release/` 폴더에 무설치 portable EXE와 설치형 NSIS EXE가 생성됩니다.

## 개인정보

모든 모니터링과 렌더링은 사용자의 컴퓨터 안에서 수행됩니다. 네트워크 업로드 기능이 없으며 렌더러에는 프로세스 명령줄을 전달하지 않습니다.
